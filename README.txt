RUCHIRA KRISHNA PORTFOLIO
=========================

This is a ready-to-upload, static portfolio website. You do not need to write code.

FILES
-----
index.html   The website content and page structure
style.css    Colours, typography and layout
script.js    Small mobile navigation interaction
assets/      Add your portfolio PDFs, images and other project files here

HOW TO PUT IT ON GITHUB
-----------------------
1. Open your GitHub repository.
2. Choose Add file > Upload files.
3. Open the unzipped folder on your computer.
4. Select the contents INSIDE the folder (index.html, style.css, script.js,
   README.txt and the assets folder) and drag them into GitHub.
5. Scroll down and click Commit changes.
6. In the repository, open Settings > Pages.
7. Under "Build and deployment", choose "Deploy from a branch".
8. Select branch "main" and folder "/ (root)", then Save.
9. Wait a minute or two. GitHub will show your website address in the Pages area.

ADDING YOUR WORK
----------------
- Put PDFs and documents in assets/documents.
- Put images in assets/images.
- Then add links to those files in index.html. The current three work cards are
  starter placeholders, not an automatic document gallery.

TWO THINGS TO PERSONALISE
-------------------------
1. In index.html, find hello@example.com and replace it with your email address.
2. Replace the placeholder work-card links and descriptions as you add real projects.
